Install on BONELAB

Avelis Hub BL runs inside BONELAB with LemonLoader and BoneLib in both Solo and LabFusion lobbies, routing networked spawns automatically through LabFusion when connected.

  1. 01. Loader Setup Prepare LemonLoader 0.6.5.1

    Back up BONELAB data and OBBs, patch with LemonLoader 0.6.5.1, grant file permissions, and complete the first launch.

  2. 02. BoneLib Dependency Verify BoneLib works first

    Install a Quest-compatible BoneLib build (compile target is 3.2.2) and confirm Bone Menu opens cleanly in game.

  3. 03. Copy Mod Assembly Drop only AvelisHubBL.dll into Mods

    Copy AvelisHubBL.dll into /sdcard/MelonLoader/<package name>/Mods/. Never copy reference DLLs into Mods.

  4. 04. Launch & Control Summon with X + Y or Bone Menu

    Enter any solo or LabFusion scene, press X + Y on your left controller, point with your right hand, and pull Right Trigger to select.
