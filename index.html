Avelis Hub BL

A Quest mod that runs inside BONELAB. Open it from Bone Menu or press X + Y together on your left controller to open the VR panel.

Download DLL Source code Install guide

Install on Quest

With LemonLoader 0.6.5.1 and a Quest-compatible BoneLib already installed, copy only AvelisHubBL.dll into your game’s existing /sdcard/MelonLoader/<package name>/Mods/ folder. In the VR panel, point with the right controller and press A to select.

Device validation pending. This package has not been tested on a physical Quest. The install guide lists supported controls and known limitations.
